# 🌐 Meus Sites Favoritos

## 📌 Sobre o projeto

O projeto **Meus Sites Favoritos** foi desenvolvido como atividade da Agenda 12 – Desenvolvimento de Sistemas I, com o objetivo de criar uma página HTML apresentando cinco sites que utilizo no dia a dia.

A página contém o nome de cada site, uma imagem ilustrativa e um link para acessá-lo.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Mantenha o arquivo `index.html` e a pasta `imagens` no mesmo diretório.
3. Abra o arquivo `index.html` em um navegador.
4. Clique nos links para acessar os sites apresentados.
